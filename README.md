# 10x-confidence-system

## Why this matters
I want to build self-trust, take bold action, and stop holding myself back.

## Daily Practice

- Take one bold action daily
- Reflect at night

## What I am learning
This system will evolve as I grow.

## My Intention
I am building self-trust, confidence, and the courage to express myself fully.
